# Этапы практики 2: что где лежит

| Этап | Метка / коммит | Как показать | Главные файлы |
|------|----------------|--------------|---------------|
| **1. Прототип с конфигурацией** | `этап-1-конфигурация` | `sh scripts/stage1_config.sh` | `src/config.py`, `src/main.py` |
| **2. Сбор данных** | `этап-2-сбор-данных` | `sh scripts/stage2_direct.sh` | `src/repository.py` |
| **3. Основные операции** | `этап-3-граф` | `sh scripts/stage3_graph.sh` | `src/graph.py` (функции `build`, `find_cycles`) |
| **4. Дополнительные операции** | `этап-4-порядок` | `sh scripts/stage4_order.sh` | `src/graph.py` (`install_order`) |
| **5. Визуализация** | `этап-5-визуализация` | `sh scripts/stage5_visual.sh` | `src/render.py` |

Всё сразу: `sh scripts/all_stages.sh`

История с метками и переход к коду этапа:

```sh
git log --oneline --decorate     # выход из листалки: q
git checkout этап-3-граф         # код на момент этапа 3
git checkout main                # вернуться к финальной версии
```

## Где какое требование выполнено

| Требование варианта 3 | Где в коде |
|-----------------------|------------|
| Параметры из INI-файла | `src/config.py`, функция `load` |
| Вывод параметров ключ-значение | `src/config.py`, метод `Config.describe`; печать в `src/main.py`, `print_settings` |
| Обработка ошибок всех параметров | `src/config.py`: `parse_bool`, `parse_depth`, `check_repository`, `read_section` |
| Формат пакетов Ubuntu (apt) | `src/repository.py`, класс `AptRepository` |
| Зависимости по URL репозитория | `src/repository.py`, функция `fetch_bytes` |
| Прямые зависимости на экран | `src/main.py`, `print_direct` |
| BFS без рекурсии | `src/graph.py`, функция `build` (очередь `deque`) |
| Максимальная глубина | `src/graph.py`, `build` -- проверка `depth >= max_depth` |
| Циклические зависимости | `src/graph.py`, `find_cycles` и `walk` (обход в глубину без рекурсии) |
| Режим тестового репозитория | `src/repository.py`, класс `TestRepository`; файлы `examples/repo_*.txt` |
| Порядок загрузки зависимостей | `src/graph.py`, `install_order` (алгоритм Кана) |
| Описание графа на Graphviz | `src/render.py`, `to_dot` |
| ASCII-дерево | `src/render.py`, `to_ascii` |
| Сравнение с apt и объяснение расхождений | `README.md`, раздел «Сравнение с реальным менеджером пакетов» |
