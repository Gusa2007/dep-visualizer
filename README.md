# Визуализатор графа зависимостей пакетов Ubuntu (вариант 3)

CLI-инструмент строит граф зависимостей пакета из репозитория Ubuntu
(apt) и показывает его как описание на языке Graphviz и как
ASCII-дерево. Данные о зависимостях разбираются своим кодом: готовые
менеджеры пакетов и сторонние библиотеки для получения зависимостей
не используются.

## Возможности

* все параметры задаются в конфигурационном файле формата INI;
* проверяются все параметры, ошибки сообщаются понятным текстом.

## Требования и запуск

Нужен только Python 3.8+ (стандартная библиотека). Для тестов --
`pytest`, для проверки стиля -- `flake8`, для картинки из описания
графа -- Graphviz (`dot`), он необязателен.

```sh
./run.sh --config examples/test_simple.ini          # Linux / macOS
run.bat --config examples\test_simple.ini           # Windows
make test                                           # тесты
make lint                                           # проверка стиля
sh scripts/all_stages.sh                            # демонстрация этапов
```

Без `make`: `python3 src/main.py --config ...`, `python3 -m pytest`.

Единственная опция командной строки -- `--config` (путь к INI-файлу);
`--order` включает вывод порядка загрузки (этап 4). Все остальные
настройки берутся из конфигурационного файла.

## Конфигурационный файл

```ini
[visualizer]
; Имя анализируемого пакета
package = curl
; URL репозитория или путь к файлу тестового репозитория
repository = http://archive.ubuntu.com/ubuntu/dists/noble/main/binary-amd64/Packages.gz
; Режим работы с тестовым репозиторием (on -- читать файл описания графа)
test_mode = off
; Режим вывода зависимостей в формате ASCII-дерева
ascii_tree = on
; Максимальная глубина анализа зависимостей
max_depth = 2
```

| Параметр     | Значение                                              |
|--------------|-------------------------------------------------------|
| `package`    | имя анализируемого пакета                              |
| `repository` | URL файла `Packages`, путь к нему или путь к тестовому репозиторию |
| `test_mode`  | `on` -- тестовый репозиторий, `off` -- реальный        |
| `ascii_tree` | `on` -- печатать ASCII-дерево                          |
| `max_depth`  | максимальная глубина анализа, целое число от 1         |

Логические параметры принимают `on/off`, `true/false`, `1/0`,
`да/нет`. Комментарии в INI начинаются с `;` или `#`.

Ошибки конфигурации сообщаются текстом и кодом возврата 1: нет файла,
нет секции `[visualizer]`, не хватает параметров, пустое имя пакета,
неверное логическое значение, нечисловая или нулевая глубина,
отсутствующий файл тестового репозитория, `repository` без URL и без
существующего файла.

## Формат тестового репозитория

Текстовый файл, строка -- пакет и его зависимости:

```
# комментарий
A: B C
B: D
C: D E
D:
```

Разделители зависимостей -- пробелы или запятые. Такой репозиторий
включается параметром `test_mode = on`.

## Как разбирается репозиторий Ubuntu

Файл `Packages` -- это записи, разделённые пустой строкой. Из каждой
записи берутся поля `Package`, `Depends`, `Pre-Depends`, `Provides`.
Строка зависимостей `libc6 (>= 2.34), libssl3 | libssl1.1` очищается
от версий, архитектурных уточнений и альтернатив: из альтернатив
берётся первая. Поле `Provides` даёт виртуальные пакеты: если
зависимость названа виртуальным именем, берётся пакет, который его
предоставляет.
